Materia: Taller de Lenguaje de Programación II
Año: 2026

### Sobre el proyecto

Proyecto desarrollado para gestionar un blog personal mediante una API REST. Permite administrar usuarios, perfiles, artículos y etiquetas, además de contar con autenticación y diferentes niveles de permisos.

Se utilizaron las tecnologías: Node.js, Express, Sequelize, MySql, JWT, Bcrypt y express-validator.

Contiene las siguientes funcionalidades:
*Registro, login y logout de usuarios.
*Autenticación mediante JWT y cookies.
*Roles de usuario y administrador.
*CRUD de usuarios, artículos y etiquetas.
*Gestión del perfil del usuario.
*Asociación de etiquetas con artículos.
*Validaciones de datos.
*Eliminación lógica y en cascada.
*Relaciones 1:1, 1 y N.
